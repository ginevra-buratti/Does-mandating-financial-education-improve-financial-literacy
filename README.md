# Replication package for "Does mandating financial education improve financial literacy? Lessons from a natural experiment"

This repository contains the public replication package for the paper *"Does mandating financial education improve financial literacy? Lessons from a natural experiment"* by A. Antonello, G. Buratti, and A. D'Ignazio.

## Data

The publicly available data used in the analysis can be downloaded, upon registration, from the INVALSI website:

- PISA 2018: https://serviziostatistico.invalsi.it/invalsi_ss_data/microdati-pisa-2018/
- PISA 2022: https://serviziostatistico.invalsi.it/invalsi_ss_data/microdati-pisa-2022/

The data are not included in this repository.

## Replication

Since the region identifiers are not included in the public-use data, all analyses reported in the paper can be replicated with the following exceptions:

- **School-level first-difference analysis:** the replication package reproduces the corresponding point estimates, but not the clustered standard errors.
- **Difference-in-differences by subject analysis:** the replication package reproduces the corresponding point estimates, but not the wild cluster bootstrap p-values.
- **Rearrangement test:** the test is not included in the public replication package.
